# 增强量价数据库

本库整理当前8个指数的原始腾讯快照，包含36,857条`date,open,high,low,close,volume`，截至2026-10-16。

- `market_ohlcv.sqlite3`：bars和calendar表，只读训练快照。
- 分类目录下8份CSV：便于Excel或其他程序查看。
- `manifest.json`：原始响应SHA256、数据库SHA256、逐指数覆盖、与原收盘库对照和缺口检查。
- 重建：仓库根目录运行 `python data/tools/build_ohlcv.py`；来源原始响应被逐段校验，未新增伪造记录，不改原market.sqlite3。

OHLC均为未复权指数点位，成交量保留腾讯原始单位。本轮仅使用序列内成交量比率等无量纲量价因子，不把原始数值跨指数直接比较；含义不清的成交额字段不导入。开高低收与量都必须为有效正数，原库覆盖和交易日历必须一致。

并未因此补齐完整市场信息：宏观数据及发布日期、估值、成分变更、基金净值、分红、费用仍缺少统一时点审计。尤其A500发布前历史属于回溯，不能宣称当时实际可交易。
