# 训练源码快照

每日推理从 `code/inference` 移至 `html/inference`，训练入口相应调整导入位置。迁移前按两轮报告中的源码 SHA256 保存原始字节，文件名为 `<SHA256>.py`。它们是训练取证资料，不是每日执行入口。

历史报告、权重与训练数据库没有改写。历史复验使用报告记录的原始指纹，源文件迁移或更新时校验这里的原始源码；模型重放仍调用当前加载器，并与全部保存预测比较。不能把旧模型报告理解成对当前已修改训练入口的重新训练证明。新训练记录当前源码路径及指纹。

默认范围从14指数缩减为8指数时，同样保存单日训练相关原始源码；历史单日复验按旧指纹读取快照并重放原模型，不把当前配置变更误认为重新训练。
