# 每日增量数据

每日服务自动建立 `market.sqlite3`（不提交 Git），保存新增日收盘价、以沪深300验证的新增交易日和最近一次更新状态。表为 `prices(code,date,close,provider)`、`calendar(date)`、`metadata(key,value)`。

原 `data/market.sqlite3`、分类 CSV、原始研究快照和训练报告保持不变。启动时先读取原历史，再合并此增量库；收盘后更新使用腾讯日线，失败尝试东方财富，至少5日重叠与价格一致性检查通过才接纳新数据，不覆盖原价格。未收盘当日数据剔除，日期缺口不补造。

若基准指数无法更新，其他指数超出已确认日历的新增行情也不接纳。接口被拒绝、字段变更或网络中断时，保留原数据与日期；页面显示更新失败。此目录不是新的完整训练快照，训练仍使用原冻结数据库。
