## 文件与字段

- `market.sqlite3`：已经构建的 SQLite 数据库，含 `series` 与 `prices` 两张表，下载后可直接用 Python 或 SQLite 工具查询。
- `indices/<方向>/<代码>.csv`：UTF-8 BOM 编码，方便 Windows Excel 打开；统一字段为 `date,code,name,close`。`close` 是价格指数点位，不是收益率，也不是基金复权净值或全收益指数。
- 同名 `.meta.json`：来源、覆盖区间、行数、SHA-256、缺日清单和口径警告。
- `catalog.json`：全部序列的机器可读目录；`registry.json`：分类与代码定义。
- `sources/`：原始下载快照及上游选取文件，可离线复查。腾讯快照保留每个分段请求的 URL、原始响应文本、SHA-256 与取得时间；日线原始响应还包含开高低收等字段。本版规范表只统一收盘价，其他字段没有跨来源混算。

这是研究用数据底座，不是已完成时点审计的训练集。后续已完成 [离线训练实验](../code/training/README.md)并保存研究参数，但未证明稳定预测优势，也未生成供网页使用的正式预测结果。

后续复查见 [2026-10-18报告](reports/readiness_2026-10-18.md)：已联网核对14条主要指数最新日期和收盘值。研究代码的功能拟合与时间因果性检查另见 [code_smoke报告](reports/code_smoke_2026-10-18.json)，不属于正式预测模型或回测结果。

## 来源与核验范围

1. **东方财富**：保存沪深300原始历史响应，作为沪深300规范序列。
2. **腾讯证券**：按两年一段获取目标和参照指数历史，核对返回的指数代码、简称和未复权 `day` 字段。请求可能带回区间外记录，整理时只保留请求窗口内的完整交易日，并按日期排序。原始字段不是前复权股票行情。其余13条规范目标序列取自这个来源；腾讯沪深300快照同时保留用于复核。
3. **[investment_data](https://github.com/chenditc/investment_data/releases/tag/2026-10-17)**：完整下载568,306,436字节归档，通过上游清单大小、SHA-256及其归档校验程序。仓库只保留宽基指数相关原始特征与观测日历，完整568MB归档不放入Git。Qlib 的 `close` 特征经过归一化，**不能当指数点位**；备用转换使用其保留的 `adjclose`，并注明 float32 精度。最终规范表优先使用直接行情源。
4. **[申万行业社区样本](https://github.com/wnt0801/a-stock-industry-rotation)**：固定提交 `73b521a3250f532a66d3ce930b59be56c5e01e1b` 的 CSV，原仓库说明数据来自AKShare。本地按行业拆分，未运行原仓库代码或采用其牛熊标签。原README说27个行业，实际CSV有28个；真实数值和分类沿革尚未通过另一独立来源验证。保留来源说明不等同于授予第三方数据商业再分发许可。

SHA-256验证证明本地文件与记录的来源快照一致；格式校验通过也不能证明行情源的每个数字都正确。

## 已发现的质量问题

- 申万社区样本大多只到2024-12-31；采掘样本只到2021-12-10。相对归档观测交易日历，大多数样本区间内缺10个交易日，采掘缺3日。均保留缺口，没有补零或前向填充。
- 上游Qlib的中证1000少1条、中证全指少600条区间内记录且停在2026-07-06。最终规范表已换用腾讯完整覆盖序列，原快照仍保留，未改写上游数据。
- 东方财富与Qlib的沪深300对照5,289条收盘记录，96条相差约0.01点；报告见 `sources/hs300_crosscheck.json`。没有强行抹平差异，也不能据此宣称来源相互独立。
- 14条规范目标和参照序列，在各自起止范围内相对于归档观测日历无缺日。取得时间不等于当年可获知时间；指数发布前回溯、历史修订和发布时间尚待正式审计。尤其不能把中证A500早期回溯记录当作当时真实存在的基金。
- 原始价格指数没有计入分红再投资、基金费用、跟踪误差和交易费用。

## 更新、重建与审计

在仓库根目录执行，Python 3.10+，无需额外依赖：

```sh
# 离线重建分类CSV和SQLite：原始快照已在仓库
python data/tools/market_data.py build

# 全量核对原始快照、哈希、日期、价格及CSV/SQLite一致性
python data/tools/market_data.py audit

# 更新14条目标与参照指数；保留独立的中证与申万口径
python data/tools/market_data.py fetch --provider tencent

# 只更新指定代码
python data/tools/market_data.py fetch --provider tencent --codes 000510 399989
```

腾讯访问目标为 `proxy.finance.qq.com`，东方财富为 `push2his.eastmoney.com`。失败返回非零状态，不会拿虚构数据替换；较短或更旧的响应不能覆盖既有历史。申万社区旧样本不由这个更新命令刷新。

更新后仍需审阅差异，再执行 `build` 和 `audit`。首次获取的覆盖范围从2005年或行情源更晚的可得日期开始，不声称这是所有指数最早的历史。离线重建不重发网络请求。

若要重新从上游完整归档导入，先从对应Release取得归档和清单，再执行：

```sh
python data/tools/market_data.py import-release --archive /path/to/qlib_bin.tar.gz --manifest /path/to/qlib_bin.manifest.json
```

脚本校验清单中的归档大小和SHA-256，只读取选定文件，不解压执行任意代码。完整上游日历语义校验的首次执行记录保存在 `sources/investment_data/2026-10-17/upstream_validation.json`。

## 查询示例

```python
import sqlite3

with sqlite3.connect("data/market.sqlite3") as db:
    rows = db.execute(
        "SELECT date, close FROM prices WHERE code = ? ORDER BY date",
        ("399989",),
    ).fetchall()
    print(rows[-5:])
```

建模时先限定指数代码与数据版本，再按交易日历构造未来5、21、63、126个交易日的标签。缺日序列不能简单用第N行代替第N个交易日。
