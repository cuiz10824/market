原例不是直接运行入口：statsmodels示例读取外部宏观数据并展示事后平滑概率；LightGBM示例依赖上游回归演示文件；scikit-learn示例使用自行车需求数据及额外绘图依赖。只归档相关代码与许可证，未复制这些演示数据，也未执行它们的联网下载。实际运行本项目数据请使用 [研究入口](../research/README.md)。

## 必须修改的地方

1. **市场状态不是预测结果。** 隐状态可能主要区分高低波动，不能直接把状态编号当“牛市/熊市”，更不能假定周期长度固定。状态命名与稳定性需要另做样本外检验。
2. **不用事后平滑状态做历史预测。** `smoothed_marginal_probabilities`使用后续观测；全历史拟合参数再回放也会带入未来。本项目只允许训练窗拟合、固定参数前向过滤，并验证修改未来数据不会改变过去过滤结果。
3. **不能照搬示例切分间隔。** 官方scikit-learn例中的48是小时场景。本项目依据标签结束日切分，半年标签必须避免跨越测试起点；多指数不能先混排再按行数分割。
4. **不在最终测试集上调参。** LightGBM示例的变量名`test`不能直接套进正式评估。早停、概率校准和参数选择均应使用内层时间验证集，最终测试区间保持独立。
5. **价格预测不等于基金投资收益。** 现有数据是价格指数，未统一分红再投资、基金费用、跟踪误差；预测涨跌概率还需要校准和样本外评估。

## 本轮未采用

- **Qlib**：适合更大型研究，常见LightGBM示例是沪深300成分股选股，目标与本项目的指数时间序列预测不同；暂不引入整套框架。
- **hmmlearn**：可做隐状态模型，但其README注明有限维护；本轮优先使用statsmodels提供可解释的状态切换模型。
- 自动交易、强化学习和大语言模型荐股项目：暂不进入数据—标签—时间验证这条基础流程。

这轮验证的是代码接口与数据管道，尚未比较方向命中率、概率校准、收益区间覆盖率或策略收益。不要根据烟雾检查结果判断哪个模型能赚钱。
