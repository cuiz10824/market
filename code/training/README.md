# 离线训练和测试

## 新增：下一交易日涨跌幅

单日回归入口 [train_one_day.py](train_one_day.py)，固定协议 [one_day_protocol.json](one_day_protocol.json)。以t日收盘为预测时点，目标是下一实际交易日收盘价/当日收盘价−1，跳过休市日。训练使用各验证时点之前全部已知标签样本；单个输入样本为最近252个交易日的15个价格特征，增加1/2/3/10日收益、5日波动。不读取未来行情，不对未知标签填充。

零变化、历史平均、岭回归、浅层LightGBM在2018—2023滚动验证选型，2024年起测试（A500从2025年起）。13个任务保留零变化、1个中证1000保留历史平均；平均测试MAE约1.037个百分点，与零变化基准基本相同，尚未验证预测优势。历史价格区间此前已被观察，本次属于探索性复测。

[完整单日报告](../../data/reports/training/oneday_20261018_f92705d5_f18f8f5f_e1190ec3/README.md)包含各行业、各年误差和9,166条预测。保存14份holdout、14份latest模型，指针为code/models/latest_one_day.json。原56个长周期模型及旧报告不变，网页每天加载两个模型集合。


## 新增：±5%三分类实验

新增分类独立于原二分类实验：大跌 `<−5%`，波动 `−5%至+5%`（含边界），大涨 `>+5%`，各期限阈值相同。原数值回归直接引用原模型及校验值，既不重新训练，也不重新选择。模型入口为 `code/models/latest_three_class.json`。

固定协议见 [three_class_protocol.json](three_class_protocol.json)。比较历史类别频率、始终波动、逻辑回归、浅层 LightGBM 和类别均衡加权版本，以滚动验证的三类宏平均 F1 选型。准确率、各类召回率、混淆矩阵及基准同时报告，防止短期波动类占多数掩盖识别能力。本次沿用此前已观察的历史测试期，属于探索性复测，不能称为新的独立验证。

仓库根目录运行：

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code/training/train_three_class.py
.venv/bin/python code/training/verify_three_class.py
```

这里负责构造样本、滚动验证选模型、独立历史测试和保存参数。日常推理只加载保存的参数，入口契约另见 [inference](../../html/inference/README.md)，不在日常程序内重新训练。

## 为什么选这些算法

收盘历史只有数千日，而半年标签高度重叠，不能当作数千个独立样本。先使用容量较小、CPU可复现的模型，避免直接引入大型神经网络：

| 目标 | 候选模型 | 选择指标 |
| --- | --- | --- |
| 上涨概率 | 历史上涨比例、63日动量规则、标准化逻辑回归、浅层LightGBM分类 | 滚动验证Brier分数越低越好 |
| 收益幅度 | 零收益、历史平均收益、标准化岭回归、浅层LightGBM回归 | 滚动验证MAE越低越好 |

输入为10个纯历史价格特征：5/21/63/126/252日动量、21/63日波动与均线偏离、252日回撤。它们描述趋势与波动状态，不预设牛熊周期固定重复。本轮未将马尔可夫状态特征与分类模型组合，之前的状态模型代码仍作为后续研究模块保留。

当复杂模型验证改善不足预设幅度时，保留简单基准。`zero`表示缺乏可验证幅度预测优势时采用0变化基准，**不是断言未来一定不涨不跌**。`constant`输出历史上涨比例，不能解释成结合今日行情得出的强信号。

## 时间规则

完整预设协议为 [protocol.json](protocol.json)，在首次运行前写入，哈希随报告和模型保存。

1. 2018—2019、2020—2021、2022—2023三段扩展训练滚动验证。模型与超参数在最终测试前确定；历史不足的验证折明确跳过。
2. 任一训练标签必须在该验证段或测试段开始前结束。验证段标签也不能越过其结束日期，避免半年标签穿越边界。标准化器只在训练集拟合。
3. 最终测试从2024年开始。中证A500训练含大量发布前回溯，其最终测试保守地从2025年开始；该处理不等于完成了回溯和成分时点审计。
4. 固定模型覆盖整个最终测试段，不在测试期间逐日偷看标签重训。测试用于观察性能，不能选择或调整模型。
5. 测试结束后，仅按已选模型种类和固定超参数，用截至数据日期已知结果的全部标签重训latest参数，供未来推理。latest重训模型没有新的独立测试成绩，不能继承holdout成绩作为保证。

半年最终测试只有约3—5段互不重叠的标签区间；同一行业及不同指数之间也高度相关。因此报告不把逐日标签当独立实验，不计算具有误导性的显著性、交易年化收益或资金曲线。

## 运行

使用Python3.12和仓库研究环境，依赖见 [requirements-research.txt](../requirements-research.txt)。在仓库根目录执行：

```sh
# Linux：限制CPU线程。Windows可直接用 .venv\Scripts\python.exe 执行同一脚本
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code/training/train.py

# 重放已保存参数与测试分数；此命令不训练
.venv/bin/python code/training/verify.py --run 20261018_5333c8a6_f18f8f5f_288545ff
```

同一日期、协议、数据和源码指纹的运行若已存在，会拒绝覆盖。重新研究应保留旧报告，修改协议形成新实验；同一天只想查看已有结果时，不必重新训练。`--codes 000300 399989`可做子集实验，子集不能注册成完整默认模型集合。

每次运行保存：

- `code/models/<run>/holdout/<代码>/<期限>/`：最终测试使用的固定参数。
- `code/models/<run>/latest/<代码>/<期限>/`：测试后重训参数，特征/标签训练截止日期写入metadata。
- `data/reports/training/<run>/`：冻结协议、数据/源码/库版本指纹、逐折分数、完整测试预测、失败或完成状态、验证报告。
- `code/models/latest.json`：通过完整重放检查后注册的默认**研究用**模型索引。

模型参数为可读JSON和LightGBM原生文本，不使用pickle。包含逻辑回归/岭回归的标准化系数、特征顺序和模型文件校验值。只保存训练过并被选中的模型，未胜出的候选保留验证分数而非冗余权重。

## 有现成的预训练模型吗

有通用时间序列模型，例如 [Amazon Chronos](https://github.com/amazon-science/chronos-forecasting) 与 [Google TimesFM](https://github.com/google-research/timesfm)，官方文档提供了可下载权重。它们不是已经在本项目14个A股指数、这几个期限上验证有效的现成模型。

本次没有下载或测试这些权重，也不把其通用基准成绩当A股预测成绩。引入前需要核对预训练数据截止时间，防止已见过本轮历史测试区间；还要核对具体权重版本许可。TimesFM当前文档对3.0权重与2.5及更早权重给出了不同许可，不能只根据源码许可判断权重用途。

目前仓库可直接加载的，是我们这次用自己的数据实际训练并保存的模型；结果仍为研究性质。后续改进应优先补估值、宏观、基金收益口径和严格时点信息，再设计新的时间验证；不承诺增加网络规模就能改善预测。
