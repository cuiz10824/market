# 五年历史输入

原模型每个样本回看252个交易日，但训练使用各切分点之前全部可用样本，而非只训练一年。新版本每个输入使用1260个交易日变化，需要1261个连续观测，近似五年。当前最新输入覆盖2021-07-30—2026-10-16。A股每年实际交易天数不固定，1260日不等于严格五个公历年。

`html/daily/cycle_features.py`共享训练和日常的142个特征：原80个短期特征加62个长期特征，包括1—5年收益、长期波动/均线/回撤/区间位置/相对成交量、20段季度收益及长期沪深300/A500相对强弱。所有计算都只读取预测时点及之前数据，缺日不填补。这是五年历史的特征摘要，不是原始日线神经网络序列。

训练仍采用扩展窗口：所有已知标签且输入完整的历史样本都会使用，不把训练样本强行限定为最近五年。由于新特征需要预热，三个长历史指数的合格起点从2010-07-15开始，其他五个从2014-09-10开始。原数据的早期记录用于形成五年输入，不是被删除。每个模型的metadata记录实际训练起止、标签截止、行数和输入跨度。

## 固定实验

- 两种模型：LightGBM-MAE、CatBoost-MAE，均固定300轮、树深5。
- 每种模型分别训练一年80特征对照和五年142特征版。四候选使用完全相同的合格训练起点、标签、验证窗和测试日期，控制因预热而减少的训练样本影响。
- 验证窗2018—2019、2020—2021、2022—2023；按所有指数标签结束日期隔离，拒绝随机混排切分。
- 测试从2024年起，A500从2025年起。价格区间此前已被观察，属于探索性复测。
- 仅五年版可获替换资格；必须在验证MAE上相对旧模型、零预测、均值、两个一年对照中最优者改善至少1%。测试集不参与选择。
- 最新输入预测下一实际交易日及未来5/21/63/126交易日累计价格收益。模型本身不假设牛熊固定3—5年循环，这需要数据检验。

## 运行

仓库根目录，使用已有`.venv`及`code/requirements-enhanced.txt`：

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code/training/train_five_year.py
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code/training/verify_five_year.py
.venv/bin/python code/training/report_five_year.py
.venv/bin/python html/predict.py
```

协议为`five_year_protocol.json`。训练保存独立`fiveyear_*`模型与报告，相同指纹拒绝覆盖。指针`code/models/latest_five_year.json`独立于旧量价指针；此前的数据、模型、报告及源码保持不变。重放验证核对60个原生模型包、95,928条候选测试预测及选择规则。

日常优先读取五年实验指针，仅为验证获批任务加载五年权重。输入缺少完整五年历史、收盘日期不一致或量价更新校验失败时提示并使用旧模型；未获批的候选仅供报告检查。日常不拟合模型，Python依赖无需新增。

原始历史尤其A500包含发布前回溯；指数价格不等于基金含分红收益。长标签重叠、跨指数相关及已观察测试区间限制绩效结论。增加时间跨度不保证提高准确率。
