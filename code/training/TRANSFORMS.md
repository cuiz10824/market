# 非线性训练目标实验

固定原有共享小TCN、756交易日输入、8指数和1/5/21/63/126交易日输出，仅比较目标变换。原始目标、asinh两档和双边指数两档共5个候选；全部参数、时间划分及预算见 `transform_protocol.json`。

已有研究环境包含全部依赖，无需新增包：

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code/training/train_transforms.py
.venv/bin/python code/training/report_transforms.py
.venv/bin/python code/training/verify_transforms.py
```

Windows可用已安装依赖的Python运行同一脚本。训练约60次小网络拟合，单进程限制2个PyTorch线程。中断后可用 `train_transforms.py --resume`；只有协议、数据、源码及已保存校验值均一致时才复用完成的拟合。同一指纹不会静默覆盖结果；源码或协议变更会生成另一实验目录。

`code/models/latest_transforms.json`仅指向本轮研究结果。模型位于独立的 `code/models/transforms_<...>/`，实验报告位于 `data/reports/training/transforms_<...>/`，不写入网页模型选择配置、不改写原训练数据库或旧模型。直接使用通用神经模型加载器会拒绝这类权重：必须用 `training.transform_engine.load` 获取变换元数据，并通过该模块的 `predict` 逆变换后才能得到真实收益。接口使用小数收益，报告及latest_predictions.csv中的预测为百分数。

目标是检验变换是否改善预测误差，不是让显示结果远离零。五种映射在归一化零点的斜率均为1；不加输出倍数、阈值、保底涨跌幅或异常收益剪裁。早停、强度和组合选择只比较逆变换后的原始收益MAE；每次训练只能读到该切分点以前已落地的标签。两个种子先各自逆变换，再平均收益；不能先平均非线性分数再做一次逆变换。

验证窗为2018—2019、2020—2021、2022—2023。每个候选根据六个验证拟合选择重训epoch，在任何测试拟合前冻结逐任务选择与重训预算。测试从2024年开始，A500从2025年开始；这些历史日期此前已经观察，因此是探索性复测。行业相关和期限重叠使样本不独立，不把小幅误差改善解释为稳定优势。

输出包括：原始单位逐折验证、逐行业/期限指标、按预测起点年份的指标、两个种子与集成、预测平均绝对幅度、低于0.01%的输出比例、MAE/偏差均值/带符号误差标准差/绝对误差标准差/RMSE、与零预测及网页现用模型的同日期比较，以及每个测试真实值和预测值。所有标准差采用ddof=0。汇总先计算各指数指标再等权平均，A500测试时段较短。

`verify_transforms.py`不重新训练，重载60份原生权重，核对所有已保存预测、时间掩码、验证选择、直接从收盘价重算的真实收益，并核对原始目标的12份模型与上一轮TCN实验一致。旧数据库、模型、报告和网页的SHA256在训练和复验时均检查。
