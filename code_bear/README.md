# 上证指数牛熊趋势研究

独立于原行业收益预测项目。只研究上海证券交易所上证指数`sh000001`，不是深市平安银行`sz000001`。

当前已收集 **1990-12-19至2026-10-22，共8737条日线**：开盘、最高、最低、收盘、成交量，保存CSV、SQLite、37份压缩原始响应和来源清单。与原仓库2000-01-04至2026-10-16的6489个观测交易日核对，无缺漏；更早日期及此后的新增日期没有声称做过独立跨源核验。成交量保留腾讯原始单位，模型只用相对量，不编造成交额。

直接双击本目录 **index.html** 可在Windows浏览器查看历史图、最新预测和测试结果，所有图片已内嵌。`output/kline_10y.png`、`output/history_cycles.png`可独立使用。

## 如何定义牛熊

图上的大趋势与未来预测分开处理：

- 历史图：按20%反转确认拐点，保存拐点日期和较晚的确认日期。末段未确认，以斜纹显示。这是事后描述，不是当时就预测到了转折，不参与训练输入。
- 未来预测：未来63/126/252个交易日（约3个月/半年/一年）累计收益达到±6%/±10%/±15%，且至少60%未来收盘处在起点相同方向一侧，才标为牛/熊趋势；其余为震荡/混合。阈值是本项目研究定义，不是官方认定。
- 当未来期限还没走完，真实标签保持未知，不补成震荡。最新预测暂时没有对应完整真实结果。

## 第一轮结果

比较多数类、过去同期限趋势延续、均线规则、多项逻辑回归和LightGBM。按2010—2013、2014—2017、2018—2021三折验证的平均Macro-F1选方案；2022年起逐年按年初已知标签重训测试，不随机打乱，不使用未来标签归一化或拟合。

三个月和半年验证选中趋势延续基准；一年选中逻辑回归。目前三个期限最新输出均为“震荡/混合”。**第一轮未证明能稳定提前预测牛熊拐点。** LightGBM一年测试Macro-F1约0.449，虽然较好，但验证并未胜出，不能看完测试后改选。多数类准确率受震荡占比影响，不能单独当成预测能力。

详细指标、类别样本数、混淆矩阵、逐年表现和逐条预测见 `models/latest.json`指向的`reports/<run>/README.md`和相邻CSV。当前结果是探索性历史对照，图示年份已经观察，不是封存的未来检验。输入只有价格与成交量，没有估值、政策或宏观信息。

## 运行

在仓库根目录，有原研究环境时可直接执行：

```sh
# 下载全历史并生成新的版本快照；未改动原项目data、code、html
.venv/bin/python code_bear/collect.py
# 新实验：固定protocol.json并训练、验证、逐年测试
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python code_bear/train.py
# 独立重放所有已保存模型与测试结果，不训练
.venv/bin/python code_bear/verify.py
# 调用验证选中的已训练模型
.venv/bin/python code_bear/predict.py
# 输出单文件网页及PNG历史图
.venv/bin/python code_bear/render.py
```

首次独立安装可以使用Python3.12创建`.venv-bear`并安装本目录requirements.txt。Windows相应解释器为`.venv-bear\Scripts\python.exe`；不需要显卡或PyTorch。已有训练版本会拒绝覆盖；修改协议后会生成新指纹目录。

日后更新数据只需依次运行collect.py、predict.py、render.py，**不需要重新训练**。预测会检查新数据包含原历史、重叠口径一致、特征顺序及源码未变、模型校验正确，且预测日期晚于训练标签截止。重新训练是独立的研究操作。没有接入原网页的后台任务，也没有更改原来的8指数模型。

## 目录

|目录/文件|用途|
|---|---|
|data/latest.json、data/<版本>/|数据指针、OHLCV CSV、SQLite、manifest、原始响应|
|bear/dataset.py|过去数据特征、未来标签、历史事后波段、时间隔离切分|
|bear/models.py|基准与分类模型，JSON/LightGBM原生保存，不用pickle|
|protocol.json|固定期限、阈值、时间切分和候选方案|
|models/<运行>/|验证、逐年测试及最新模型和分割预测|
|reports/<运行>/|冻结方案、验证选择、测试指标、逐条输出、校验|
|output/|可更新的最新预测与历史PNG|
|index.html|无需Python即可打开的结果页面|
|tests/|未来信息隔离、单位不变性、标签掩码、拐点确认、原生权重重载|

单元测试：`.venv/bin/python -m unittest discover -s code_bear/tests -v`。所有回测以预测日收盘为信息边界；不是盘中预测，不含基金分红、交易成本或可执行交易策略收益。
